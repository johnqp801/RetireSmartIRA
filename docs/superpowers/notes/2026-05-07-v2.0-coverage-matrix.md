## Headline gaps if I had to pick the top 5

1. **Per-year "why this much, why this year" reasoning cards** — the brainstorm called this *the* differentiation moat. Without it, V2.0 is "Boldin with nicer charts."
2. **Editable year overrides + downstream re-narration** — "user is the editor, not consumer" is foundational, not optional.
3. **Appreciated stock donation input** — the action item shows but the user can't configure or change the inputs.
4. **Liquidity headroom visualization** — the brainstorm called this "the most underrated real-world constraint." Engine has it; user can't see it.
5. **Assumption Panel as a real first-class panel** — pills are nice but they're not the assumption transparency the brainstorm specified.
